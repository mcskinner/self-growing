# Left chat

## Intent
Keep the working chat in a left-hand pane, leaving a right-hand workspace for the app to grow into.

## Boundaries
This is a layout adaptation, not a Markdown reader. Preserve existing chat behavior and avoid adding backend capabilities.

## Success
On a wide screen, chat and workspace are visible side by side; the chat transcript scrolls without displacing its composer. On a narrow screen, chat remains usable without horizontal overflow. Sending, steering, stopping, and starting a new chat still work.
